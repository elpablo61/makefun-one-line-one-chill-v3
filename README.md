One sentence of horror, under 200 characters. A judge model compares the lines
head to head on how frightening, vivid and original they are.

## The line (151 characters, one sentence)

> My grandmother hums the first bar of a lullaby before she opens a door; last night, from the empty room at the end of the hall, I heard the second bar.

## How it works

`main.ts` (Node 22) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). The gate requires UTF-8 text of 1–200 characters.

## Run

```sh
node main.ts
cat /output/entry.txt
```
